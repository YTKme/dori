# Phase 0

## Overview

I want to build a simple [CRM](https://en.wikipedia.org/wiki/Customer_relationship_management) system like Salesforce and Odoo. It should have the basic functionality that [Salesforce](https://www.salesforce.com/) and [Odoo](https://www.odoo.com/) provide. Do some research on the Internet, there might be other examples as well.

## Technology

- TANSTACK START
- shadcn/ui
- PostgreSQL
- drizzle (use the RC version)

## General

- Follow industry best practices for CRM system design and architecture.
- Ignore all the AI features the system might have for now.
- The application should be able to deploy as an "appliance" if you will. Meaning it should be self-contained and easy to install and configure on a server without requiring extensive external dependencies. (e.g., [docker](https://www.docker.com/) and [docker compose](https://docs.docker.com/compose/))

## Rule

- Use [RESTful](https://en.wikipedia.org/wiki/REST) [API](https://en.wikipedia.org/wiki/API)s only.


## Note

- Let me know if there are any questions.
- Make sure to follow industry best practices for system design and architecture. Don't just blindly follow instructions. Think before acting.
